# `lab-lightsail` 운영 실행서

이 디렉터리는 완성 템플릿을 브라우저에서 수동 업로드하여 파일럿을 설치하고 확인하고 삭제할 때 사용하는 실행 순서입니다. `standard-aws`는 아직 설계 단계이므로 이 절차로 만들 수 없습니다.

> 현재 `v0.1.3` 완성 템플릿을 다운로드할 수 있습니다. `v0.1.2` 실제 시험에서 공인 IP 인증서 적용과 갱신 timer 설치는 성공했지만 worker 내부 Nginx Host 검사에서 중단됐습니다. 수정한 `v0.1.3`은 아직 실제 AWS 재시험 전입니다.

## 권장 순서

1. [설치](install.md)에서 비용, 권한, 데이터 손실 위험을 확인합니다.
2. [상태 확인](status.md)에서 CloudFormation 완료 상태와 Outputs를 확인합니다.
3. 문제가 있으면 [로그 확인](logs.md)과 [문제 해결](../troubleshooting.md)을 따릅니다.
4. 버전을 바꾸려면 [업데이트](update.md)와 [롤백](rollback.md)의 제한을 먼저 읽습니다.
5. 실험을 끝내면 [삭제](uninstall.md)에서 모든 잔존 자원을 확인합니다.

## 반드시 기억할 제한

- 기본 사양은 서울 리전의 4GB 메모리, 2 vCPU, 80GB SSD, 월 4TB 전송량 Lightsail 번들입니다.
- 공식 표시 가격은 월 **US$24**입니다.
- 고정 IP는 인스턴스에 연결된 동안 무료이며, 연결되지 않은 동안 시간당 **US$0.005**가 청구됩니다.
- 자동 스냅샷, 애플리케이션 백업, 데이터 복구 작업을 만들지 않습니다.
- 따라서 스택, 인스턴스 또는 디스크를 삭제하면 QFieldCloud 데이터가 영구 손실됩니다.
- 설치가 실패해도 인스턴스나 고정 IP가 남을 수 있습니다. CloudFormation과 Lightsail을 모두 확인해야 과금을 멈출 수 있습니다.
- 이 파일럿은 기존 식물이력관리 PostGIS 데이터베이스와 연결하거나 변경하지 않습니다.

정확한 범위와 현재 게시 상태는 [`lab-lightsail` 안내서](../lab-lightsail.md)를 먼저 확인하세요.

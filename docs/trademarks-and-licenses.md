# 라이선스와 상표

## 확인된 사실

QFieldCloud 공식 저장소의 [검토한 릴리스는 MIT License](https://github.com/opengisch/QFieldCloud/blob/c32bc110f8291b2a32e318528ee46689771630d6/LICENSE)를 게시합니다. QField 앱은 별도 저장소와 라이선스를 가지므로 이름이 비슷하다는 이유로 같은 조건이라고 가정하지 않습니다. 외부 이미지와 라이브러리도 각각의 라이선스를 확인해야 합니다.

## 프로젝트 권고

- QFieldCloud 소프트웨어 또는 상당 부분을 재배포하면 해당 저작권과 MIT 고지를 유지합니다.
- 릴리스 전 사용한 모든 외부 구성요소의 이름, 버전, 출처와 라이선스를 기록합니다.
- 공식 로고를 프로젝트 로고로 사용하지 않습니다.
- 저장소와 README 상단에 독립적인 비공식 프로젝트임을 한국어와 영어로 표시합니다.
- OPENGIS.ch가 제작·승인·보증하거나 지원하는 설치 프로그램처럼 표현하지 않습니다.
- 공식 상표 지침이 추가로 확인되면 현재 문서보다 해당 지침을 우선합니다.

## 불확실성

이번 단계에서는 모든 상황에 적용할 수 있는 공식 세부 상표 정책을 확정하지 못했습니다. 이름 사용은 호환 대상 설명에 필요한 범위로 제한하고, 공개 로고나 홍보물을 만들기 전에 최신 정책을 다시 확인합니다. 이 문서는 법률 자문이 아닙니다.
